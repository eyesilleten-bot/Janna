# Janna

Janna is a beginner-first programming language designed to be readable, simple, and practical.

## Current version

0.1.1

## What Janna V1 can do

- variables
- output
- conditions
- loops
- tasks
- lists
- objects
- files
- JSON
- error handling
- build `.ja` programs into Windows `.exe` files

## Installation

Run `JannaSetup.exe`.

After installation, open a new PowerShell window and run:

janna version

## Your first Janna program

Create a file called `hello.ja`:

name is "Ege"

show "Hello {name}"

Run it with:

janna run hello.ja

Build an executable with:

janna build hello.ja

## Syntax layers

Janna V1 currently uses the natural syntax layer.

Keyboard shorthand and symbolic/alien syntax are planned for later versions.
