# Janna

Janna, programlamaya yeni başlayanlar için okunabilir, sade ve pratik olacak şekilde tasarlanmış bir programlama dilidir.

## Güncel sürüm

0.1.1

## Janna V1 şu anda neler yapabiliyor?

- değişkenler
- ekrana çıktı verme
- koşullar
- döngüler
- task yapısı
- listeler
- object yapıları
- dosya işlemleri
- JSON işlemleri
- hata yakalama
- `.ja` programlarını Windows `.exe` dosyasına dönüştürme

## Kurulum

`JannaSetup.exe` dosyasını aç.

Kurulumdan sonra yeni bir PowerShell penceresi aç ve şunu yaz:

janna version

## İlk Janna programın

`hello.ja` adında bir dosya oluştur ve içine şunu yaz:

name is "Ege"

show "Hello {name}"

Çalıştırmak için:

janna run hello.ja

EXE oluşturmak için:

janna build hello.ja
